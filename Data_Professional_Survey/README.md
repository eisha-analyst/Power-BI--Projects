# Data Professional Survey Breakdown

## 📊 Project Overview
This Power BI dashboard analyzes a survey of data professionals worldwide, covering salary, job satisfaction, and programming language preferences.

## 📁 Files in this Repository
- Power BI - Final Project.xlsx — Raw dataset
- Transform Dataset.pbix — Power BI file with transformations and dashboard
- p.png — Dashboard screenshot

## 📈 Dashboard Highlights
- Total Survey Takers: 630
- Average Age: 29.87
- Countries: USA, India, Canada, UK, and Others
- Work/Life Balance Happiness: 5.74/10
- Favorite Programming Languages by Job Title
- Difficulty to Break Into Data field
- Average Salary by Job Title

## 🛠️ Tools Used
- Microsoft Power BI
- Power Query (Data Transformation)
- Microsoft Excel
